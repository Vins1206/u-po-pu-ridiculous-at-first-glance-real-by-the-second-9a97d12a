## What it does

`main.py` writes one sentence — at most 200 characters — pitching a bizarre
startup idea to `/output/entry.txt`:

> We lease retired circus clowns as corporate mediators, and HR teams pay $400 a session because nobody stays furious while a clown juggles their complaint forms.

The pitch names the weird thing being sold (retired circus clowns as
corporate mediators), who pays (HR teams, $400 a session), and why the
logic holds (nobody stays furious while a clown juggles their complaint
forms). Pure Python standard library, fully deterministic: every run
writes the exact same bytes.

## How to run it

```bash
python3 main.py
cat /output/entry.txt
```
